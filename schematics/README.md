# Schematics

Designs the villagers can build with `build_schematic` (and list with `list_schematics`). Files are WorldEdit/Sponge `.schem` or legacy `.schematic` files.

## Included

| File | Credit | Licence |
|---|---|---|
| `smallhouse1.schem` | [PrismarineJS / mineflayer-builder](https://github.com/PrismarineJS/mineflayer-builder) | MIT, see [LICENSE-mineflayer-builder.txt](LICENSE-mineflayer-builder.txt) |

Despite its name, `smallhouse1` is a 21 x 20 manor, 28 blocks tall, with about 3,200 blocks: a long-term village project.

## Adding your own

Download a `.schem` file (for example from a schematics website) and put it in this folder. Add a line for it to `credits.json` so the villagers credit its creator when they build it.

Designs you download belong to their creators. This folder's `.gitignore` keeps them out of your GitHub upload; only the files listed above are shared.
